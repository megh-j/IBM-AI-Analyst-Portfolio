# 🤖 IBM AI-Analyst

This repository contains a comprehensive collection of machine learning models and data analysis tasks completed during the IBM AI Analyst program. 

This project features practical Python implementations of supervised and unsupervised learning algorithms, including regression, classification, clustering, association rules, and dimensionality reduction, bridging theoretical data science concepts with hands-on coding.

# ✨ Features

Predict continuous variables using Linear Regression

Classify outcomes using Logistic Regression, SVM, and KNN

Perform text and sentiment classification using Naïve Bayes

Build complex predictive models using Decision Trees and Random Forests

Evaluate model performance using Confusion Matrices and accuracy metrics

Group data using K-Means, Hierarchical, and DBSCAN clustering

Perform Market Basket Analysis using Apriori and FP-Growth algorithms

Reduce dataset dimensionality using Principal Component Analysis (PCA)

Visualize dendrograms, clusters, and confusion matrices using Matplotlib

# 🛠️ Technologies Used

Python 3

Scikit-Learn (sklearn)

Pandas & NumPy

Matplotlib

MLxtend (for Association Rules)

Jupyter Notebook / Google Colab

# 🚀 Programming & Data Concepts Practiced
This project demonstrates the use of:

Data pre-processing and standardization (StandardScaler)

Model instantiation, fitting, and prediction (.fit(), .predict())

Text vectorization for NLP tasks (CountVectorizer)

Hyperparameter tuning (e.g., n_clusters, eps, min_samples)

Market Basket Analysis metrics (Support, Confidence, Lift)

Data visualization (Scatter plots, Dendrograms, Heatmaps)
