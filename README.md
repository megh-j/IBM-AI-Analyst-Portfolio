# AI-Analyst-IBM-Course-Assignments
📌 Project Overview
This repository contains a comprehensive collection of machine learning models and data analysis tasks completed during the IBM AI Analyst program. The assignments bridge theoretical data science concepts with practical, hands-on Python implementation, covering a wide spectrum of both Supervised and Unsupervised Learning algorithms.


🛠️ Tech Stack & Libraries
Language: Python
Data Manipulation: Pandas, NumPy
Machine Learning: Scikit-Learn (sklearn)
Association Rule Mining: MLxtend (Apriori, FP-Growth)
Data Visualization: Matplotlib
Environment: Jupyter Notebook / Google Colab

📚 Syllabus
Linear Regression
Logistic Regression
Naïve Bayes
K-Nearest Neighbors (KNN)
Support Vector Machines (SVM)
Tree-Based Models
Model Evaluation
Clustering Algorithms: K-Means, Hierarchical Clustering, DBSCAN, Algorithm Comparison
Market Basket Analysis (Association Rules):
Apriori Algorithm, FP-Growth, Business Insights
Dimensionality Reduction (PCA): Principal Component Analysis
Analyzed and reported the Total Variance Retained by the reduced components
